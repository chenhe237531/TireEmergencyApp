# 地图选点使用高德，坐标统一 GCJ-02

## Status

accepted

## Context

司机常在高速、国道、厂区，仅靠文字描述位置不够精确。uni-app App 端的地图与定位默认适配高德，而地图 SDK 会在启动时采集设备与位置信息，必须先取得用户同意。

## Decision

v1 使用高德定位与 `uni.chooseLocation` 地图选点，坐标统一为 GCJ-02；首次启动先展示隐私弹窗，用户同意后才初始化地图 SDK 并申请定位权限。Key 绑定 Android 包名与签名 SHA1。

## Consequences

- 隐私政策必须列明高德 SDK 收集的信息与用途，首次启动未同意前不得初始化 SDK。
- 拒绝定位权限时保留手动填写位置的通路，不阻塞救援提交。
- 后续切换地图服务商需要同时更换 Key、坐标系与隐私声明，成本较高。
