# v1 与小程序对等，只加地图选点与一键拨号

## Status

accepted

## Context

平台的核心闭环是「司机提交需求 → 客服电话核实并调度门店」，司机不需要在线支付，也不应该看到门店电话与详细地址。

## Decision

v1 功能与微信小程序对等（附近门店、故障找救援、救援咨询、我的记录、FAQ、关于、分享），并增加三项安卓增强：地图选点定位、客服一键拨号、提交草稿与弱网重试。明确不做：厂商推送、在线支付、门店端、门店分布地图。

## Consequences

- 状态变化依赖前台轮询与本地通知；真正的后台推送推迟到上架商店后的 v2。
- 地图选点引入高德 SDK，需要配置 Key 并完成隐私合规初始化。
- 门店分布图不做，避免暴露门店密度并与门店脱敏策略冲突。
