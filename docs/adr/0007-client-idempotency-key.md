# 提交工单使用客户端幂等键，不依赖时间窗口去重

## Status

accepted

## Context

服务端现有的防重复逻辑是“同一司机 2 分钟内已有进行中工单则拒绝”，它只能覆盖连点，无法覆盖弱网下超过 2 分钟的重试；安卓司机在高速、国道经常遇到断网，自动重试可能产生重复救援工单，导致客服重复外呼与门店重复派单。

## Decision

救援与咨询提交由客户端生成 `clientRequestId`（UUID），与草稿一起持久化，所有重试复用同一个值；服务端按 `(driverId, clientRequestId)` 唯一索引识别，重复请求直接返回原工单，不新建记录。原有的 2 分钟窗口保留，用于没有幂等键的旧客户端。

## Consequences

- 客户端必须在首次提交前落盘幂等键，杀进程后重试仍能命中同一工单。
- 游客提交咨询时 `driverId` 为空，幂等约束不生效；安卓端引导登录后再提交。
- 旧版小程序无需改动，行为保持不变。
