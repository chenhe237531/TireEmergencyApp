# 注销账号时匿名化个人信息，保留工单统计骨架

## Status

accepted

## Context

国内应用商店要求 App 提供账号注销入口，个人信息保护法要求注销后删除个人信息；但救援工单是客服调度与门店结算的追溯依据，物理删除会破坏运营记录。

## Decision

注销时对司机资料做匿名化（手机号、openid、昵称、头像清空，状态置为 deleted），工单保留状态、时间、门店与操作流水，但清空车牌、坐标、位置描述、故障描述、联系人、电话与现场图片；浏览痕迹与本人上传的文件删除。

## Consequences

- 注销后同一手机号可以重新注册，新账号不继承历史工单。
- 客服与运营看到的历史工单可用于统计，但无法再联系或定位当事人。
- 注销需要二次短信验证，避免令牌被盗后恶意注销。
